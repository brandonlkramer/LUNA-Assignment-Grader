Getting an assignment ready to grade

Do this once for each assignment. Everything goes into the class's LUNA Assignments folder, which the grader made inside the folder you chose for the class.

  1. Download the students' work. On the assignment's page in LUNA, under Batch Download, click Download all submissions. When the Download (date and time) link appears, click it. You get a .zip file.
  2. Unzip it into the class's LUNA Assignments folder (Mac: double-click the .zip; Windows: right-click → Extract All). This makes a folder named like …assignment_status_Week_1_Homework_…. The grader can't read the .zip itself.
  3. Download the grading template. Under Comment and Grade, click Download Format. This gives a file named like …assignment_comment_format_250565.xlsx.
  4. Move the template into the unzipped folder from step 2, so everything for this assignment is together.

When you've finished grading: press Save LUNA upload file. A file ending in _GRADED.xlsx appears in the assignment's folder. Back in LUNA, under Comment and Grade, click Reference, choose that _GRADED.xlsx file, then click Upload.
